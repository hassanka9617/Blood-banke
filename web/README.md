# نسخة الويب — مخزون مصرف الدم

نسخة HTML تعمل دون إنترنت بنفس منطق تطبيق أندرويد (الاستلام، الإضافة، الصرف، التسوية، الإلغاء الموثق،
إنهاء الخفارة والترحيل، التقارير، سجل التدقيق، النسخ الاحتياطي). البيانات تُحفظ على الجهاز (localStorage).

## التحويل إلى APK عبر webintoapp.com
1. ارفع الملف `BloodBank-web.zip` (موجود في جذر المستودع) في خيار **Upload HTML / ZIP**.
2. فعّل في الإعدادات (إن وُجدت): **Enable file upload** و **Enable downloads** و **Enable DOM storage / Local storage**.
3. أنشئ التطبيق وحمّل الـ APK.

> مهم: لا تحذف التطبيق المحوّل ولا تمسح بياناته قبل أخذ نسخة احتياطية من شاشة "النسخ الاحتياطي".
